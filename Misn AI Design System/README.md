# Misn AI - Design System

> A mission operating system for founders.
> Black, paper, red. Clean structure. Intense enough to move, restrained enough to trust.

Misn AI is a founder operating system for knowing what matters now. The product should feel personal without getting soft, professional without becoming cold, and directional without becoming noisy.

This package replaces the older forest-and-gold Misn direction with a darker monochrome system built around one purposeful action color.

## Direction

- `Mission black` anchors the product and keeps it serious.
- `Paper white` keeps reading, planning, and focus surfaces clear.
- `Signal red` is used for action, the current move, active states, and moments of commitment.
- `Warm grey` and `mist` support structure without drifting into generic SaaS blue or utility grey.

The result should feel like a private founder console, not a decorative productivity app and not a generic AI dashboard.

## Tone and voice

- Speak to one founder, not to a market segment.
- Be clear before clever.
- Use calm direction, not hype.
- Frame progress as structure and momentum, not gamification.

Examples:

> "Protect the mission."

> "Choose the next meaningful move."

> "Less scattered. More directed."

## Visual rules

- No green botanical identity in the active system.
- No gold luxury signaling in the active system.
- No purple, cyan, or default AI gradients.
- Use red with discipline. It should guide action, not flood every surface.
- Prefer black layers, subtle borders, mono labels, and one strong focal element.

Some preview and UI-kit files still keep older class names such as `movaris-card` for compatibility. The visible brand and active token system are now `Misn AI`.
